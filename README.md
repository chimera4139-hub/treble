# Treble 1.1 (native, iPod touch 4 / iOS 6.1.6, jailbroken)

Objective-C / UIKit, built with Theos into a .deb that installs to /Applications/Treble.app.
Files: main.m, Screens.m/.h (all screens), TBTheme.m/.h (theme engine), TBPlayer.m/.h (audio engine), TBStore.m/.h (library).
Themes: Old Apple, Modern, Spotify, FM, Poster - each with Light / Dark, plus Auto (dark 7pm-7am). More > Theme / Light-Dark.
Music goes in /var/mobile/Media/Treble/Inbox, then Create > Scan (Spotify theme: Library > +).
Debug log: /var/mobile/Media/Treble/.data/log.txt
